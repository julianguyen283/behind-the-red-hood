# Media files

The site reads these exact filenames. Upload a file with the same name to replace one.
Alt text, captions, transcript and timed text are set in `src/content/media.ts`.

The current files are AI-generated samples, made in code by the scripts in `tools/media/`. The voice is a synthetic stand-in.

| File | Used for |
|---|---|
| `video/intro.mp4` | Opening film (44 s) |
| `images/intro-poster.webp` | First frame of the opening film |
| `captions/intro.vtt` | Opening film sound captions |
| `audio/grandmother-voice.mp3` | The voice from the bedroom (22 s) |
| `images/illustration-1.webp` | Illustration 1: the bedroom from the doorway |
| `images/illustration-2.webp` | Illustration 2: the hood on the thorns |
| `audio/ambience.mp3` | Background sound for the Sound on / off button (64 s loop) |

Keep each file under 25 MB if you upload on github.com.
